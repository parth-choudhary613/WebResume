# WebResume

React 19 + Vite 7 + Tailwind CSS 4 portfolio with Three.js, React Three Fiber and a WebGL background.

## Develop

```bash
npm ci
npm run dev
```

## Check and ship

```bash
npm run verify:static
npm run lint
npm run build
npm run preview
```

See [PERFORMANCE_REPORT.md](PERFORMANCE_REPORT.md) for changes, verified source-level savings, browser validation checklist and remaining limitations. **Production build and browser regression verification are required before deployment** because dependency installation was unavailable when this optimized archive was prepared.
